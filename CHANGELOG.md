## [0.1.0] - 2026-09-26

### Added

- Initial project foundation and architecture setup.
- Brand logo optimization into WebP, multi-size favicon, and PWA icons in `public/brand/`.
- Technical post-war industrial design system with custom palette (Background, Surface, Slate Metal, Bone White, Red Slate).
- Interactive UI mockup covering Landing Page, Main STACK Workspace, Write/Split/Read Markdown modes, Command Palette, Settings panel, and mobile responsive layout.
- Prerender-ready public routes (`/`, `/docs`, `/help`, `/changelog`) and CSR application shell (`/app`).
